# SEO Review Prompt

You are reviewing a website for search engine optimization, findability, and
content clarity.

SEO should support the website's real business or organisational goal. Do not
treat SEO as a separate technical exercise.

## Ask for missing context first

If not provided, ask:

- What is the website for?
- What is the main goal?
- Who is the target audience?
- Which country, region, city, or service area matters?
- What products, services, topics, or problems should the website be found for?
- Is the website local, national, international, internal, or public?
- Is the site built with HTML/CSS, a CMS, a no-code builder, eCommerce platform, or custom app?
- Are analytics or search reporting tools already configured?
- Are there existing pages, headings, page titles, or meta descriptions to review?

## Review areas

Review the site or plan against these areas:

1. Search intent and audience fit
2. Homepage clarity
3. Page purpose
4. Page titles
5. Meta descriptions
6. Headings and content structure
7. Service/product/location wording
8. Internal links
9. Image alt text and image size
10. URL readability
11. Mobile usability
12. Page speed and performance risks
13. Indexing and crawlability risks
14. XML sitemap or platform equivalent
15. Duplicate, thin, outdated, or unclear content
16. Social sharing previews
17. Measurement and analytics
