## Why This Document Was Replaced

The original 1,300-line guide was written before the website artifact system
expanded to 40+ prompts, 8 skills, and structured workflows. Maintaining two
overlapping guides created drift risk. The shared guide in `_copilot-shared/`
is the single source of truth and is synced to every project automatically.
